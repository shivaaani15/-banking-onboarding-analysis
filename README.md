# Banking Customer Onboarding Analysis

## Project Overview
This independent portfolio project explores how a bank could
identify delays and drop-offs in its digital account-opening process.

It combines SQL analysis with business process mapping,
requirements documentation, and dashboard development.

## Business Problem
Customers may abandon account applications before completion.
Applications may also experience delays during document review
and identity verification.

This project will investigate where these issues occur and propose
improvements supported by the analysis.

## Key Questions
1. What percentage of applications result in an opened account?
2. At which stage do the most applications drop off?
3. Which stages take the longest to complete?
4. How do completion rates differ across application channels?
5. What process changes could address the issues identified?

## Planned Deliverables
- Business problem statement and project scope
- Synthetic dataset and data dictionary
- SQL queries and findings
- Current and proposed process maps
- Business requirements and acceptance criteria
- Dashboard and recommendations

## Tools
- SQL: data exploration and analysis
- Excel or Power BI: dashboard and visualisation
- GitHub: project documentation and version history

## Data and Limitations
This project will use synthetic data created for learning.
It does not contain actual bank or customer information.

Recommendations will be proposals, not implemented changes.
No business impact will be claimed without supporting evidence.
